$ cat principles.md
Four non-negotiables behind every codebase I touch — and where you can see them.

001 · Architecture Clear boundaries between layers and dependency rules that keep features replaceable. A controller that knows about the database is a controller I will rewrite.

002 · Correctness over cleverness Money is BigDecimal, never a float. Concurrent writes get optimistic locking, not hope. Identity is compared by value, not by reference — a lesson bigint ids teach you exactly once.

003 · Migrations you can prove Porting a live backend means the schema cannot drift. Mine is verified by a harness that boots a throwaway Postgres, runs every migration and diffs the dump against production. Green or it does not ship.

004 · Security at the boundary Validation at every edge, least-privilege access, tenant isolation enforced in one place instead of thirty. The dangerous auth bug is not the one that throws — it is the one that silently lets you through.

OrderNow — multi-tenant restaurant platform
QR menus for diners, dedicated kitchen and bar panels, floor and delivery management, and a real-time sales dashboard. Built for restaurants in Argentina.

The part worth talking about is underneath:

A strangler-fig migration of the whole backend. 32,000+ lines of Spring Boot 3 ported to NestJS 11 — wire-compatible down to the JWT claims, the response envelope and the error DTO, so both backends could serve live traffic during cutover. Known bugs from the original were ported on purpose: during a cutover, correctness is the enemy of compatibility.
Schema drift caught automatically. A harness spins a throwaway Postgres, runs every migration, dumps the schema and diffs it against production. A silent drift in a live migration is not a bug you find in code review.
Tenant isolation enforced in one place. AOP aspects with explicit ordering rather than an access check copy-pasted across every controller.
Money handled properly. BigDecimal end to end, optimistic locking on concurrent checkout, transactional boundaries where they belong.
Telescope — a self-built APM for the Java side: request tracing, JVM metrics collector, cache hit/miss counters and a query inspector.
